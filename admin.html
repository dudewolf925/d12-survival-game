🎲 D12 Admin Studio

Edit your game on your iPhone. Copy the configuration and publish it in GitHub when ready.

Game settings

For a public game, hosted image URLs are recommended. Small photos can be embedded in the configuration.

Slides

D12 rolls select slides 1–12. Consequence branches can lead to slides 13–24. Slide 16 is the winning slide.

Supabase leaderboard

Enter only your public project URL and publishable/anon key. Never enter a secret or service_role key.

Save and publish

Save Draft stores edits on this iPhone. Copy Configuration gives you the JSON to paste into a GitHub file named game-config.json.
