Slides

D12 rolls select slides 1–12. Doubles and consequence branches can lead to slides 13–24. Slide 16 is the winning slide.

Paste a RedGIFs watch link, an Imgur link, or a direct image/video URL. The game detects supported media automatically.

🖼️ Second Gallery Item

Optional. Add a second image, GIF, or video. Your game displays a swipe gallery when both media URLs are filled in.

😈 Swipe Left If You Dare

When a player moves from Media 1 to Media 2, a surprise popup appears for 5 seconds. Customize its message for every slide.

Leave this blank to use the default popup message. The message is stored in swipeMessage for each slide.

⏱️ Slide Timer Settings

This timer starts when the slide appears. It controls how long the player must wait before rolling again.

😈 Additional Swipe Lockout

If a player swipes to Media 2, the YOU DARED! popup appears for 5 seconds. The additional swipe timer begins only after the popup closes.

Set this to 0 to disable the additional swipe lockout. Each slide can have its own duration.

🚀 Publish to GitHub

Your saved draft loads automatically. Publishing saves your draft first, then checks GitHub's version without replacing your edits.

Your GitHub token stays securely in Supabase. Your publishing password is never saved in game-config.json. If GitHub changed since your draft's known version, publishing stops rather than overwriting those changes.
