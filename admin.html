🚀 Publish to GitHub

Your saved draft loads automatically. Publishing saves your draft first, then checks GitHub's version without replacing your edits.

Your GitHub token stays securely in Supabase. Your publishing password is never saved in game-config.json. If GitHub changed since your draft's known version, publishing stops rather than overwriting those changes.
