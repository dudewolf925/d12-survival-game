🎲 D12 Admin Studio

Edit your game on your iPhone and publish changes directly to GitHub using your secure Supabase connection.

Game settings

For a public game, hosted image URLs are recommended. Small photos can be embedded in the configuration.

Slides

D12 rolls select slides 1–12. Consequence branches can lead to slides 13–24. Slide 16 is the winning slide.

Supabase leaderboard

Enter only your public project URL and publishable/anon key. Never enter a secret or service_role key.

Reset Leaderboards

Danger zone: This permanently deletes every saved player score. The Soldier Leaderboard and Hunter Scoreboard will both reset to empty.

Your game slides and configuration will not be deleted.

The password is sent only to your protected Supabase function. It is not saved in your game configuration.

🚀 Publish to GitHub

Load the current GitHub configuration before editing. When ready, publish your changes directly to game-config.json.

Your GitHub token stays securely in Supabase. Your publishing password is never saved in game-config.json.

Save and publish

Save Draft stores edits on this iPhone. Copy Configuration gives you JSON to paste into GitHub manually if needed.
